# 1. ABSOLUT WICHTIG: SSR

Die gesamte Landingpage muss **server-side rendered (SSR)** umgesetzt werden.

Das ist eine harte technische Anforderung.

Ziel:

* vollständiges HTML bereits auf dem Server rendern
* relevante Inhalte müssen ohne JavaScript im initialen HTML vorhanden sein
* Googlebot muss die komplette Landingpage direkt crawlen können
* Title, Meta Description, H1, H2, Fließtexte, FAQs und lokale SEO-Inhalte müssen im initialen HTML vorhanden sein
* keine zentrale Content-Ausgabe ausschließlich über Client-Side JavaScript
* keine reine SPA
* keine clientseitige Rendering-Abhängigkeit für SEO-relevante Inhalte

Wenn du Next.js verwendest, nutze die App Router Architektur und Server Components, wo sinnvoll.

Interaktive Elemente wie Formulare, Slider oder Menüs dürfen Client Components sein, aber der eigentliche SEO- und Conversion-Content muss serverseitig gerendert werden.

Prüfe nach Fertigstellung explizit, dass die Landingpage auch bei deaktiviertem JavaScript die wesentlichen Inhalte ausliefert.
